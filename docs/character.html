Lab A · 【3】负反馈速度控制器

蹬地是一脚一脚付出去的

设定速度不是一个被强行钉住的目标，而是一个稳定不动点。努力度随速度下降，阻力随速度上升，两条曲线只交于一点。推力按离散的一脚交付，所以画面里看到的是蹬地动作，不是匀速传送带。

D(v) = g·Crr + (ρ·CdA / 2m)·v² + g·i // 阻力，连续积分 E(v) = 1 / (1 + (v/vset)⁶) · clamp(1 − (v/18)², 0.15, 1) A₀ = min(2.6, D(vset) / E(vset)) // 解在设定点 owed += A₀·E(v)·dt if owed ≥ 0.85 and t − lastPush ≥ 0.42s: owed −= 0.85; v += 0.85; 蹬地动画触发 v += −D(v)·dt // 连续项只有阻力

为什么是六次方

E(v) 需要在设定点附近有一个陡膝：低于设定速度时努力度≈1（少年在追速），高于时迅速→0（不再加速）。六次方让 v=0.8·vset 时 E≈0.79、v=1.2·vset 时 E≈0.26，过渡带只有 ±20%。后一项 (v/18)² 是体能天花板：18 m/s = 64.8 km/h 是冲刺极限，地板 0.15 保证再快也还有一点点蹬地，不会变成完全滑行。

负反馈的证明（不是调参调出来的）

令 f(v) = A₀·E(v) − D(v)。E′(v) ≤ 0 且 D′(v) = 2·Kair·v > 0，所以 f′(v) < 0 对所有 v>0 成立：f 严格单调递减，最多一个零点；而 A₀ 的构造让 f(vset) = 0。故 vset 是唯一且全局稳定的不动点。离散交付只是把连续推力切成脉冲，长期均值不变。

已踩过的陷阱：推力被付了两次

早先连续项写成 a = A₀·E − D，同时又 v += 0.85。平衡条件于是变成 2·A₀·E(v) = D(v)，实测设定 8 却稳定在 9.046（+13.08%）。右侧「连续项也加推力」开关可以当场复现这个错误——红色虚线就是被翻倍的推力曲线，交点右移。

失效边界一：A₀ 饱和

A₀ 被 A_CAP = 2.6 m/s² 夹住（这是少年能持续输出的加速度）。当 vset > 10.8666 m/s 时 A₀ 触顶，推力不足以维持设定速度：设定 12 → 实际 11.403（−4.98%），设定 16 → 实际 12.599（−21.25%）。滑杆上限 16 是愿望，不是承诺。右侧读数会在触顶时亮红。

失效边界二：纵坡只重分配速度

A₀ 按 i=0 解算，所以恒定上坡会破坏锚定（右侧纵坡滑杆可验证）。但真实路线是闭环，净爬升为零：上坡掉的速度下坡补回来。实测 150 s：均值 7.978（−0.27%），瞬时 6.828–9.198（纹波 29.6%），上坡均速 7.668 / 下坡 8.321，36.4 脚/分。长期锚定，短期呼吸——这正是想要的。

Lab B · 【2】侧倾 + 【4】头部耦合

躯干对齐有效重力，头对齐世界

稳态转弯里，"下"不是重力 g，而是 geff = g + (−a离心)。躯干必须对齐 geff，否则合力不通过板面接触线，人就翻了。头可以偏离这条线——颈部能施加力矩——但偏离不是免费的：它移动整体重心，并消耗颈部力矩预算。

【4】头部三条真实机制

① 前庭-颈反射（VCR）· 潜伏期 ~60–100 ms

内耳感知头部在空间中的转动，经颈肌反射把 head 稳定住，潜伏期约 60–100 ms（文献量级设计取值，本方案取 80 ms）。所以头相对躯干是一阶滞后，不是刚性同步。滞后让压弯入弯时头"慢半拍"，出弯时头"先回正"——这正是真人看起来的样子。

② 视线锚定 · 超前 0.3–0.5 s

骑手先把头转向弯道顶点再压弯（ anticipatory gaze ）。取 0.35 s（设计取值），在 8 m/s 时前视 2.8 m。侧倾的前视量则取 clamp(v·0.67, 3, 12) m——两者不同：视线看得更远更早，身体反应稍晚。

③ 头部质量参与重心 · 偏离由力矩买单

头质量取体重 8% = 4.4 kg，重心高 1.5 m。头相对躯干偏离 Δθ 时整体重心横移 (mh/m)·h·sin Δθ：5° → 1.05 cm，10° → 2.08 cm，15° → 3.11 cm，20° → 4.10 cm。板面接触斑半宽约 0.09 m，所以 15° 就吃掉了 34.5% 的稳定裕度。颈部力矩 τ = mh·|geff|·d·sin(θhead − θg_eff)，d = 0.12 m（寰枕关节到头部重心）。持续预算取 12 N·m（设计取值）。

【2】体能上限怎么体现

κh = 水平投影曲率（纵坡不压弯） alat = κh·v² θwant = atan(alat / g) · leanGain θtrunk = clamp(θwant, ±leanMax) θhead = LPFτ=80ms( θtrunk·(1 − c) )

上限放宽，而不是把物理角乘大

"身体素质非常好"落在 leanMax = 0.52 rad = 29.79°（横向 0.573 g）与 leanGain = 1.0（纯物理协调角）。普通骑手的舒适侧倾约 20–25°，末世少年放到 29.79°。gain 保持 1.0 意味着不伪造物理：想更夸张只能调 gain，但那会偏离协调角。

两个天花板正好互相咬合

在最小半径 24.277 m 处，能完全协调（不被 clamp）的速度上限是 11.677 m/s；而速度控制器的 A₀ 饱和阈是 10.8666 m/s。也就是说控制器先触顶，侧倾后触顶——正常玩法里少年永远不会出现"压不下去"的姿态。只有手动连续蹬地把速度顶过 11.7 m/s 才会看到 clamp 亮红，那是玩家自己造成的失控边缘。

atan 与线性的差

v=14 / R=22：alat = 8.909 m/s²（0.908 g），atan 给 42.24°，线性近似 θ≈alat/g 给 52.03°——高估 9.8°。低速时两者几乎相同（v8/R24.277：15.04° vs 15.40°），所以这个错误只在高速暴露。右侧读数实时显示两者之差。

Lab C · 路线随机化 · 右转闸门

不自穿是构造出来的，不是抽样抽出来的

中心线用星形极坐标闭合环：R(u) = R₀·(1 + Σ ak·sin(k·u + φk))，约束 Σ|ak| ≤ 0.40 ⇒ R(u) > 0 恒成立 ⇒ 从原点出发的每条射线只穿过曲线一次 ⇒ 水平投影不自交是数学保证。整数谐波让 u=0 与 u=2π 的位置和各阶导数精确闭合，接缝处不会跳。

k=1 缺席 // 一次谐波只是平移，不产生弯 k=2 椭圆化 a ∈ [0.08, 0.16] k=3 非凸 a ∈ [0.10, 0.15] // 反号曲率的来源 k=4 细节 a ∈ [0.010, 0.035] R₀ 由二分解锁到 L = 295 m（灯距整除、圈速、内存都挂在 L 上） 弧长表 NSAMP=2048 → M = round(L/0.25) → STEP = L/M

STEP 必须反解，不能写死

写死 STEP = 0.25 会让 M 个 0.25 与真实 L 差 0.014 m，接缝处采样落在错误的环上。反解 STEP = L/M 后 s=L 精确映回环 0。这是上一轮修掉的一个潜伏缺陷。

符号约定：正 = 右转

cross(T, dT)·[0,1,0] ≥ 0 为正。解析验证：u=0 处 T=(1,0,0)，R=cross(U,T)=(0,0,−1)，dT ∝ (0,0,−1) = +R，所以正号确实指向画面右。作者要求"有右转的地方"，闸门因此强制左右弯各 ≥2 段、每段 ≥12 m，而不是只看总曲率。

闸门与实测通过率

200 个种子扫描：最小半径 ≥22 m 通过 67%，≥26 m 通过 0%——最小半径是唯一的紧约束，且紧弯全是右弯（右弯中位 R 22.9 m，左弯中位 30.9 m）。纵坡 ≤4.5% 通过 47%，双向弯各 ≥2 段通过 74%。三条合起来 21.5%，平均 4.7 次尝试命中，所以拒绝采样是廉价的。

失效边界：这不是合规线形

R = 22 m 仍是《公路路线设计规范》高速极限最小半径的约 1/11。这是为了在 ~35 m 雾深内看得见弯而故意压缩的。旧 Fourier 路线的纵坡达 |ty| = 0.196（11.3° / 20%），那是任何高速隧道都不可能的坡度，新闸门把它压到 4.5% 以内（种子 137 实测 4.062%）。

星形只保证水平不自交

两条相隔很远的弧仍可能靠到 2·RAD 以内，所以运行时真量一遍非邻近段最小间距（守卫 14 m，步长 4）。闸门要求 ≥ 2·RAD+2 = 8.3 m；种子 137 实测 13.811 m，余量 66%。下面画布会把任何违规段标红。

当前壁纸包里的人物仍是 v4 的剪影 + 物理侧倾。蹬地与压弯已经作用于速度与侧倾（Lab A / Lab B 就是实装的那套数学），但尚未作用于骨骼——那要等 M1–M4 的执行顺序。示意图里的 IK 是本方案的设计验证，不是已交付的运行时。

世界观 → 美术方向

荒废不是调暗，是失效

"灾变后末世"不能靠把画面调暗来表达。暗只是曝光低；荒废是系统不再工作：灯成段熄灭而不是整体变暗，海报被撕开而不是褪色，瓦砾堆在路侧而不是均匀撒噪点，墙上留着幸存者写给下一个人的话。

死灯：回路级故障，三处同时归零

不是每盏灯独立掷硬币，而是成段熄灭（一段 1–5 盏，模拟回路故障）。一盏死灯必须同时从三个地方消失：肋实例色 → 0.035、辉光顶点色 → 黑（加色混合下零贡献）、点光源只挂在活肋上。少杀一处，灯就只是"变暗"而不是"坏了"。另有 10%·decay 的濒死灯在闪烁。实测种子 137 / decay 0.72：19/33 盏死灯（57.6%）。

海报：风化 + 幸存者喷涂

图集 3 列 × 4 行 = 768×1536。风化在烘焙期做：褪色填充、destination-out 撕角、9 团霉斑、5 道垂直水渍。运行时滑杆只驱动自发光衰减、死灯比例与瓦砾数量——拖动滑杆时重烘一张 768×1536 图集要几十毫秒，不能每帧做。第 9–11 格是幸存者覆盖层：出口箭头 +「出口 / 300 m」、四组计数刻痕 +「有人吗 / 第 41 天 / 往东别走回头」、黄色三角 +「塌 方」+ 警示斜条。实测 33 张海报。

瓦砾：构造上避开骑行线

二十面体实例，横向位置 |x| ∈ [0.70, 0.97]·WF，而少年在 x≈0——骑行线永远干净，不需要碰撞检测。尺寸 0.10 + 0.34·r1.7（幂律让大多数是小碎块、少数是大塌落）。数量 min(260, RIB_N·3.4·decay)，实测 81 块。decay=0 时完全消失，画面回到灾变前。

三个预设 = 三个时间点

荒废高速·钠灯穿山隧道（decay 0.72，现在）／应急回路·冷白管廊段（decay 0.55，应急灯还活着的那一段）／灾变前·霓虹下穿道（decay 0.30，记忆里的样子）。同一条路线、同一个种子，只换灯色与荒废度——世界观因此有了纵深，而不是三张不相干的图。

色板 · 点击复制

全部取自隧道本身：钠灯、应急回路、出口标识、铁锈、警示漆、混凝土、沥青。暖色交给灯，混凝土只保留真实反照率量级。
