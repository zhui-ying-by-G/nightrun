# 无限隧道 · 世界观设定
## World Bible · v1.0 · 指导生产用

> **文档性质**：这不是小说设定，是生产手册。每一条设定都必须能落到一个资产、一个参数、或一个镜头语言上。
> **适用范围**：美术、建模、动画、关卡、文案、音频、交互设计。
> **一句话**：灾变之后，壁垒把安全围了起来，把世界留在了外面。一条不在任何地图上的废弃高速穿山隧道，一个用滑板读路的少年，和他护着的那点东西。

---

## 0. 阅读方式

- **§1–§4 是世界的地基**，所有岗位都必须读，决定“什么合理、什么不合理”。
- **§5–§7 是角色的生产规格**，建模、动画、交互岗重点读。
- **§8–§10 是隧道的生产规格**，关卡、美术、音频岗重点读。
- **§11–§13 是约束与检查清单**，所有岗位交付前对照。
- 每条设定后标注了 **【落点】**，指向具体资产或参数；标注 **【禁止】** 的是硬边界。

## 1. 世界总览

### 1.1 灾变

不写清楚。只写它**留下的结构**。

那场把天烧白的事之后，世界没有被毁灭，而是被**重新分区**了。旧有的行政、交通、通信网络大部分还在物理层面存在，但**不再有人维护**，也不再属于任何人。文明不是崩塌，是**撤退**——退进壁垒，把外面留给了时间。

**【落点】** 世界观文本中永远不出现“核战”“病毒”“AI叛乱”等具体成因。所有角色提到灾变时只用代称：“那事”“天亮那次”“旧世最后一场交易”。

**【禁止】** 不做灾变前史的时间线年表。玩家不需要知道，角色也不完全知道。

### 1.2 壁垒

编号越小，越靠近权力与资源。壁垒内部有秩序、配给、身份登记；壁垒外部是集镇、废墟、和**没有人登记在册的空白地带**。

壁垒不是恶的。它只是**有边界的**。它的逻辑是：保护里面的人，代价是外面的人不在保护范围内。这个逻辑不需要被批判，只需要被呈现。

**【落点】** 壁垒在画面中永远不直接出现。只通过三种间接信号存在：
- 远处地平线上偶尔的**探照灯光柱**（微事件）
- 流民口中提到的**编号**（文案）
- 隧道墙上幸存者写的**“往东别走回头”**（涂鸦）

**【禁止】** 不做壁垒内部场景。不做壁垒守卫角色。不做“冲进壁垒”的剧情。

### 1.3 缝

壁垒之间不是荒野，是**缝**。废弃高速、穿山隧道、断裂高架、被遗弃的服务区。这些东西在灾变后没有被清除，因为**壁垒没有动力去清理“外面”**。

缝的功能：
- 流民的非正式通道
- 走私路线
- 信息流通的灰色渠道
- **没有人收税的地方**

主角在缝里活着，不是因为他选了自由，是因为**缝里没人收税**。

**【落点】** 隧道是缝的一种具体形态。它不是“末世景观”，是**基础设施的遗骸**。所有场景设计必须符合“曾经有人维护、现在没人维护”的逻辑。

## 2. 地理与空间

### 2.1 这条隧道在哪

一条穿山高速的一段。两端都通向壁垒的辖区，但**中间这段谁管不着**。这是它成为“缝”的原因。

隧道在地图上的状态：**不在任何壁垒的登记地图上**。它曾经在旧世的地图上有编号，但那个编号已经没人用了。

**【落点】** `tunnel.*.json` 中 `world.bulwarkProximity: "none-official"`。

### 2.2 隧道的物理规格

| 项 | 规格 | 说明 |
|---|---|---|
| 截面 | 马蹄形（拱 + 平路面） | 旧世高速隧道的标准截面 |
| 净高 | 约 5.1 m（拱顶到路面） | 人物身高 1.62 m，比例约 1:3.2 |
| 管半径 | 3.15 m | 建模基准 |
| 路面宽度 | 约 6.3 m（双车道 + 路肩） | 滑手主要在右侧车道行驶 |
| 灯带 | 拱顶两侧，间距约 9 m | 钠灯，部分已死 |
| 路面 | 沥青，有裂缝、碎石、局部积水 | 破损程度由 `decay` 参数控制 |

**【落点】** `tunnel.*.json` 中 `section.radius`、`section.floorRatio`、`section.ribSpacing`。

### 2.3 隧道为什么是闭环

工程上它是为了“无限循环”。叙事上它是为了另一件事：**隧道没有尽头，所以它不属于任何一端**。两端都通向壁垒的辖区，但中间这段谁管不着。主角在这段里循环，等于在**两套秩序之间的空白**里活着。

**【落点】** 闭环是数学事实，不需要叙事解释。但角色对闭环的**态度**需要设计——他可能已经习惯了，甚至不再意识到自己在循环。

## 3. 社会与生存

### 3.1 流民

壁垒外的人口。没有身份登记，没有配给，靠集镇交易、拾荒、走私、和**互相之间的默契**活着。

流民不是“野蛮人”。他们有自己的规矩：
- 不主动攻击同类（除非为了生存）
- 不碰别人挂在身上的东西（那是底线）
- 在隧道里遇到其他人，**默认不交谈，各走各的**

**【落点】** 微事件中出现的其他流民：远处车灯、墙上新增的涂鸦、路面上的新刹车痕。**永远不出现面对面的流民角色**——那会破坏孤独感。

### 3.2 集镇

壁垒外的非正式聚居点。有交易、有信息、有短暂的秩序。主角偶尔会去集镇换取补给，但**不在集镇停留**。

**【落点】** 集镇在壁纸中不出现。只在角色的背景设定中存在，影响他的装备和补给逻辑。

### 3.3 信息

在缝里，信息比物资更值钱。谁知道哪段路塌了、哪个壁垒在招人、哪条隧道最近有“东西”出没——这些信息通过涂鸦、口头、和**遗留物**传播。

**【落点】** 隧道墙上的涂鸦是信息层的核心载体。每一条涂鸦都必须有**具体的作者意图**（警告、指路、求救、标记）。

### 3.4 生存法则

- **安静比快重要。** 隧道里不只有你。
- **不留下痕迹。** 痕迹会引来跟踪。
- **护住你身上的东西。** 那是你唯一不需要解释的财产。

**【落点】** 滑板作为交通工具的选择理由：安静、省力、不留下痕迹。

## 4. 时间与变化

壁纸的时间尺度是**小时**，不是三十秒。世界观必须支持三层时间尺度。

### 4.1 短周期（32.8 秒 · 一圈）

**庇护所仪式。** 每圈经过同一个弯道、同一盏坏掉的灯、同一处渗水。这是主角确认“我还在这条路上”的仪式。

**【落点】** 每圈的几何、贴图、灯距必须完全一致。这是闭环的技术要求，也是叙事要求——**重复本身就是安全感**。

### 4.2 中周期（3–18 分钟 · 微事件）

**信息层。** 墙上偶尔出现的涂鸦、路面上新增的刹车痕、远处一闪而过的车灯。这些是其他流民留下的信号。

主角不一定每次都停下来看，但**他看得到**。

**【落点】** `event.*.json` 中的微事件时间轴。每个事件必须有明确的触发条件和持续时间。

### 4.3 长周期（8 小时 · 漂移）

**世界变化。** 洞口天光从冷白慢慢偏暖，或者从灰黄慢慢变暗。不解释是天气、季节、还是别的什么。

挂一整天的人，傍晚会发现“好像不太一样了”。

**【落点】** `tunnel.*.json` 中 `world.timeOfDay` 的慢速漂移参数。

**【禁止】** 不做明确的昼夜循环。天光变化必须是**模糊的、不可归因的**。

## 5. 主角

### 5.1 基本设定

| 项 | 设定 |
|---|---|
| 称呼 | 未定（工程代号：rider） |
| 年龄 | 少年（约 14–17 岁，具体未定） |
| 性别 | 未定（少年感优先） |
| 身高 | 1.62 m |
| 体型 | 偏瘦，但核心力量好（长期滑板 + 野外生存） |
| 装备 | 滑板、背包、护具（简化）、一件旧外套 |
| 护着的东西 | **未定**（徽章 / 变异小动物 / 一段隧道壁 / 其他） |

**【落点】** `rider.*.json` 中 `height`、`style`、`pose`。

### 5.2 性格

底色参考任小粟，但只取**生存哲学**，不取剧情：

> “这世界想活下去的人就干净不了。”

但同时保留一条**极窄的底线**——对极少数人负责。

| 特质 | 表现 |
|---|---|
| 幽默健谈、脑回路清奇 | 独处时自言自语，对着隧道壁的涂鸦搭话，给废弃路标起外号。**话多，但只说给自己听。** |
| 对外冷漠果决 | 遇到其他流民，不主动帮忙，也不主动伤害。但如果对方动了他挂在板头的那个东西，他会突然变得很不“冷静”。 |
| 渴望知识 | 收集旧世遗留的公路地图、隧道养护手册、还能读出数据的车载导航残骸。不识字的部分靠猜，猜错骂一句，接着猜。 |
| 底线极窄但存在 | 他护的东西很小。**不大，但谁碰谁死。** |

**【落点】** 文案和动画中体现。独处时的自言自语可以做成**极低频的音频层**（默认静音，可选开启）。

### 5.3 技能

| 技能 | 说明 | 生产落点 |
|---|---|---|
| 读路 | 从路面起伏判断前方 30 m 有无塌陷 | 蹬地/压弯的决策依据（叙事层面） |
| 静滚 | 滑板在破损路面上的低噪行驶 | 滑板动作设计原则 |
| 路线记忆 | 记住隧道每一段的细节 | 微事件的感知能力 |

**【落点】** `rider.*.json` 中 `rider.skills`。

### 5.4 那个小动作

每次过接缝过曝的那一瞬间，他会**眯一下眼**。

不是怕光，是这条隧道里唯一不需要看路的一秒钟。

**【落点】** 这是世界观里最便宜、也最容易被记住的细节。不需要台词，不需要 UI。动画岗在接缝过曝的 0.42 秒内加入一个**眼部/眉部的微表情**即可。

### 5.5 滑板

不是玩具，是**读路的工具**。

| 项 | 规格 |
|---|---|
| 板长 | 0.82 m |
| 板面 | 旧世标准板，有磨损、贴纸残留 |
| 轮子 | 偏软，适应破损路面 |
| 声音 | 低频滚动声，不刺耳 |

**【落点】** `rider.*.json` 中 `board.length`、`board.pitchGain`。

**【禁止】** 不做发光板、不做悬浮板、不做科幻改装。它是旧世遗物，不是未来科技。

## 6. 隧道的叙事层

隧道在这条世界线里不是背景，是**角色**。它承担三个叙事功能，对应三层时间尺度。

### 6.1 庇护所（短周期）

头顶有东西，风被挡在外面，变异生物没那么容易从上面下来。

每一圈经过的同一个弯道、同一盏坏掉的灯、同一处渗水，是主角**确认“我还在这条路上”的仪式**。

**【落点】** 灯、渗水、裂缝的位置必须由 `seed` 确定性生成，每圈完全一致。

### 6.2 信息层（中周期）

墙上偶尔出现的涂鸦、路面上新增的刹车痕、某一段灯突然亮了又灭，都是其他流民留下的信号。

**【落点】** 涂鸦内容必须有具体意图：
- **警告类**：“塌方”“前面有水”“别走左边”
- **指路类**：“出口 / 300 m”“往东别走回头”
- **计数类**：刻痕 + “第 41 天”“有人吗”
- **标记类**：个人符号、帮派标记

**【禁止】** 不做“到此一游”式的无意义涂鸦。每一条都必须有作者、有意图、有时间感。

### 6.3 世界变化（长周期）

天光从隧道口渗进来的颜色变化。不解释成因。

**【落点】** 只改一个参数：`portalColor` 的色相和明度。不改变几何、不改变灯光布局。

## 7. 视觉语言

### 7.1 色彩系统

全部取自隧道本身。暖色交给灯，混凝土只保留真实反照率量级。

| 色名 | 色值 | 用途 |
|---|---|---|
| 钠灯 | `#ffab4d` | 主色族，灯管直视 |
| 钠灯高光 | `#ffd7a2` | 灯芯 / 轮廓光 |
| 钠灯深 | `#c96a12` | 辉光衰减 / 滑块 |
| 应急冷青 | `#3fe3ff` | 应急回路 / 左转标识 |
| 出口苔绿 | `#9fd356` | 出口标识 / 合格状态 |
| 铁锈 | `#b4462a` | 锈迹 / 警示漆 |
| 危险红 | `#ff4d4d` | 失效 / 超预算 |
| 警示黄 | `#f2c14e` | 塌方三角 / 注意 |
| 混凝土 | `#1c2126` | 管壁表面 |
| 沥青 | `#080a0c` | 路面 / 背景 |
| 老化纸 | `#c9bda4` | 暖中性 / 正文 |
| 冷灰 | `#8fa3b8` | 冷中性 / 矢量 |

### 7.2 光

- **全场景 ≤ 3 类光源**：顶灯带 + 洞口天光 + 板底冷光。
- **主色温 ≤ 2 个**：钠灯 2100K / 天光 6500K，比例 8:2。
- **人物亮度 ≤ 8%**：剪影 RGB ≤ `#141414`，仅留 1 px 边缘光。
- **雾**：45 m 见底，透过率 0.15，远端溶进天光而非黑色。

**【落点】** `tunnel.*.json` 中 `lighting`、`atmosphere`。

### 7.3 材质

- **墙面**：低频噪声，纹理周期 ≥ 2 m，禁止高频噪点。
- **路面**：湿沥青（部分路段），有裂缝、碎石、局部积水。
- **金属**：锈迹，非镜面反射。
- **海报**：风化、撕角、霉斑、水渍。幸存者喷涂覆盖在风化层之上。

**【落点】** `assets/textures/wall_noise_512.png`，可平铺，灰度。

### 7.4 剪影

- 人物是**剪影**，不是模型。只需要一个可信的轮廓和重心。
- 反照率 `#08080a`，轮廓光 `#ffc27a`，宽度 0.012。
- **不做骨骼动画**（v1）。姿态由曲率、坡度、节奏驱动。

**【落点】** `rider.*.json` 中 `style.albedo`、`style.rimWidth`、`style.rimColor`。

### 7.5 镜头语言

| 项 | 规则 |
|---|---|
| 机位 | 侧后方跟随，偏移量固定 |
| FOV | 垂直 56°，锁定，不做呼吸 |
| 抖动 | 禁止 |
| 速度线 | 禁止（用灯带掠过频率表达速度） |
| 运动模糊 | 禁止（用拉长的灯光表达） |

**【落点】** `core/camera.js` 中机位参数。

## 8. 声音设计

### 8.1 环境层（默认开启，低音量）

| 声音 | 说明 |
|---|---|
| 低频隧道嗡鸣 | 持续底噪，频率约 40–60 Hz |
| 灯管电流声 | 活灯有微弱电流声，死灯无声 |
| 风声 | 从洞口方向传来的断续风声 |
| 滑板滚动声 | 低频、不刺耳，随速度变化 |

### 8.2 事件层（默认开启）

| 声音 | 触发 |
|---|---|
| 远处车灯 | 微事件：对向车灯闪过 |
| 通风机低频 | 微事件：某段通风机短暂启动 |
| 水滴 | 微事件：渗水处滴水 |

### 8.3 角色层（默认关闭）

| 声音 | 说明 |
|---|---|
| 自言自语 | 极低频，几乎听不清内容，只作为“有人在”的信号 |
| 蹬地呼吸 | 每次蹬地时的轻微呼吸声 |

**【落点】** `assets/audio/`，v1 空着，v1.2 再放。

**【禁止】** 不做背景音乐。不做戏剧化音效。所有声音必须是**环境本身的**。

## 9. 微事件清单

微事件是中周期时间尺度的核心。每个事件必须有明确的触发条件、持续时间、和叙事意图。

| 事件 | 类型 | 持续 | 叙事意图 |
|---|---|---|---|
| 远处车灯 | 视觉 | 0.8 s | “有人刚从另一个方向过来” |
| 墙上新增涂鸦 | 视觉 | 持续 | “有人在这里留下过信息” |
| 一只飞虫 | 视觉 | 6 s | “这里还有生命” |
| 通风机启动 | 音频 + 视觉 | 3 s | “旧世的基础设施还在苟延残喘” |
| 某段灯突然亮起又灭 | 视觉 | 1.5 s | “电路还没完全死” |
| 对向滑板声 | 音频 | 2 s | “这条路上不只有你” |
| 路面新增刹车痕 | 视觉 | 持续 | “有人在这里急停过” |

**【落点】** `event.*.json` 中 `events[]` 数组，每个事件有 `at`（触发时刻）、`type`、`dur`、`params`。

**【禁止】** 不做“突然出现怪物”“突然爆炸”等惊吓型事件。所有事件必须是**安静的、需要留意的**。

## 10. 预设：三个时间点

同一条路线、同一个种子，只换灯色与荒废度。世界观因此有了纵深。

| 预设 | 名称 | decay | 灯色 | 叙事定位 |
|---|---|---|---|---|
| `sodium` | 荒废高速 · 钠灯穿山隧道 | 0.72 | `#ffab4d` | **现在**。灯大部分已死，瓦砾堆积，海报风化。 |
| `cold` | 应急回路 · 冷白管廊段 | 0.55 | `#d6e9ff` | **应急状态**。应急灯还活着的那一段，灯距更密，节奏更硬。 |

## 11. 生产约束

### 11.1 做什么

- 程序化生成一切几何。零外部模型资产。
- 剪影角色。不做绑定、不做动画。
- 闭合曲线路线。种子可换。
- 三层时间尺度。短周期重复，中周期微事件，长周期漂移。
- 单文件打包。`file://` 下可运行。

### 11.2 不做什么

| 禁止项 | 原因 |
|---|---|
| 叙事解谜 | 桌面不需要第二个游戏 |
| 操作玩法 | 默认零交互 |
| 角色商城 | 角色是轮廓，不是商品 |
| 在线加载 | Lively 环境的硬约束 |
| 真实运动模糊 | 代价高、效果脏 |
| 镜头抖动 | 八小时后是折磨 |
| 常驻 UI | 任何文字、按钮、水印默认不出现 |
| 背景音乐 | 破坏环境感 |
| 壁垒内部场景 | 世界观不需要 |
| 面对面流民角色 | 破坏孤独感 |
